# Context-Aware-Audio-Guidance-System-for-the-Visually-Impaired

My ongoing project is a Context-Aware Audio Guidance System designed for visually impaired people. The main goal of this project is to help users navigate independently by providing real-time audio feedback about obstacles in their surroundings.

The system is designed as smart wearable glasses equipped with a camera that continuously captures the environment. A Raspberry Pi acts as the central processing unit, where the captured video is processed in real time to detect objects and obstacles in front of the user. Along with object detection, the system also estimates the distance between the user and the obstacle, which helps in understanding how close or critical the obstacle is.

Based on the detected object and its distance, the system generates contextual voice guidance through earphones, such as alerts about nearby obstacles or safe paths. To keep the glasses lightweight and comfortable, heavier components like the Raspberry Pi and power supply are designed to be worn separately.

The focus of this project is on real-time performance, reliability, and user comfort, making it suitable for real-world use. Overall, this project demonstrates my skills in embedded systems, computer vision integration, and assistive technology design.
