# Context-Aware-Audio-Guidance-System-for-Visually-Impaired

Built a fully standalone assistive system on Raspberry Pi 4; camera detects objects in real time and generates directional audio
prompts based on proximity - runs without a laptop or external device.
Implemented a distance-to-audio mapping layer converting bounding-box estimates into context-aware spoken cues for real-time
navigation assistance for visually impaired users.
Field-tested while walking in real environments; audio guidance responded correctly to obstacles and adjusted prompts based on
relative object distance. Entire codebase written in Python.
